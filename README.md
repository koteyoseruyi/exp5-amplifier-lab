# 实验五：单管交流放大电路交互指导

模块式九孔插件板与实验仪器的中文教学网页。直接打开在线网址即可使用，不需要注册。

## 功能

- 33 个逐步演示：九孔板装配、静态工作点、旁路电容、负载与增益、饱和和截止失真。
- 九孔组连通提示、透明插件块安装、完整接线预览与手机放大查看。
- 示波器通道/耦合/量程/时基/触发/反相/测量，信号源幅值单位与输出，万用表、电源操作。
- 按指导书表 5-2 至 5-5 填实测记录，保存在当前设备，可导出 CSV。
- 自动恢复上次步骤；首次在线加载成功后，可在网络中断时使用缓存。支持加入手机主屏幕。

## 使用

从“安装九孔板”开始，点“演示这一步”；也可以直接预览完整接线或载入正常波形自由练习。手机上的九孔板可横向滚动。

仪器波形和读数是教学模型，不能替代实验测量。空白记录表用于填写课堂实测值。更换接线或元件前关闭直流电源和信号源。

记录保存在浏览器中，不上传服务器；换浏览器或设备时不会自动同步，建议导出 CSV。

## 发布与文件

本仓库是静态站点，无编译步骤。GitHub Pages 的源设为 main 分支根目录。
入口是 index.html；assets 中是脚本、样式和图片；sw.js 提供离线缓存。
下载 ZIP 并完整解压后可在本地浏览器打开 index.html；离线缓存安装仅在 HTTPS 在线访问时启用。

参考照片由本任务用户提供，用于说明九孔板结构。仪器菜单参照 Tektronix MSO2000B 用户手册及 AFG1000 官方资料。本项目不附原始实验 PDF、私人数据或认证凭据。
